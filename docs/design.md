# 公開の設計（費用0円・Web で一般公開）

数字は Cloudflare の公式ページ（2026-11-26 に読んだ）から。無料枠は変わるので、公開前にもう一度確かめる。

## 置き場：Cloudflare の無料プラン（Workers Free）1つにまとめる
| 部品 | 使うもの | 無料枠 | このサービスでの使い方 |
|---|---|---|---|
| 画面 | Workers の静的ファイル（`*.workers.dev`） | 10万リクエスト／日 | 独自ドメインは有料なので最初は workers.dev |
| API | Workers | CPU 10ms／回（AI・DB の待ち時間は数えない） | 引用の照合・URL 差し込みだけなので収まる見込み |
| 埋め込み | Workers AI `@cf/baai/bge-m3`（多言語） | 10,000 neurons／日（全モデル合計、0時 UTC に戻る） | FAQ 全件の登録で約1,100 neurons（1回だけ）。質問1件はほぼ0 |
| ベクトル検索 | Vectorize | 保存 500万次元・照会 3,000万次元／月 | 4,413件×1,024次元＝約452万次元で保存枠に収まる。照会は（4,413＋質問数）×1,024 なので**月 約2.4万問まで** |
| ログ・費用 | D1 | 同上 | 質問・検索結果・使った neurons・判定を1行ずつ |
| 荒らし対策 | 1 IP あたりの回数制限＋1日の上限（Turnstile はまだ） | 無料 | 無料枠を1人で使い切られないように |

ローカルの埋め込みモデルは、公開すると質問のたびに動かす置き場が要り、無料にならないのでやめる。FAQ 側と質問側は同じモデル（bge-m3）で埋め込む必要がある。

## 検索の計測（2026-11-26・答えられる200問）
| 方式 | 上位1件 | 上位3件 | 上位5件 | 上位10件 |
|---|---|---|---|---|
| キーワード（文字 n-gram TF-IDF） | 33.0% | 49.5% | 59.5% | 68.5% |
| **埋め込み（bge-m3）** | **73.0%** | **89.0%** | **96.0%** | **98.5%** |
| 併用（順位の逆数の和） | 56.0% | 72.5% | 80.5% | 88.5% |

- 埋め込みだけで上位5件の合格ライン（95%）を超えた。キーワードを混ぜると下がるので、**キーワード検索はやめて埋め込みだけ**にする（D1 の全文検索も要らない）
- 外れた8問のうち A119・A154 は、1位の FAQ も実質答えている（正解の FAQ が1つしか登録されていない）
- 1位の類似度だけでは「FAQにない」問と分けられない（答えられる問の下から10% 0.637、FAQにない問の上から10% 0.700）→ 回答可否はモデルの判定が要る（設計どおり）
- 作り直し：`scripts/embed.py`（wrangler dev を立ててから）→ `scripts/eval_retrieval.py`

## 生成モデルの選定（2026-11-26・50問＝試行30＋FAQにない10＋意地悪10）
| 生成モデル | 期待の FAQ で回答 | 別の正しい FAQ で回答 | 原文表示に落ちた | FAQにない・意地悪で答えた | neurons／問 | 秒（中央） |
|---|---|---|---|---|---|---|
| **gemma-4-26b-a4b-it** | 25/30 | 4/30 | 1/30（検証が厳しすぎ） | 2/20（どちらも正しい振る舞い：前提の訂正・FAQの数字だけ） | **13.9** | 6.1 |
| glm-4.7-flash | 0/30 | — | 30/30 | 0/20 | 26.0 | 15.5 |

- **生成は gemma-4-26b、検証は llama-4-scout-17b**（別モデル）に決めた。引用元にない内容の回答は 0 件
- glm-4.7-flash は考える出力で上限を使い切り、45/50 で JSON が返らなかった
- qwen3-30b-a3b は 2026-11-20 に提供終了。deepseek-v4.1-flash は有料プランが要る
- 1問 約14 neurons → **1日 約600問まで無料**（有料換算 約0.02円／問）。設計時の見込み（50）の3分の1

## 300問の計測（2026-11-26・gemma-4 生成＋llama-4-scout 検証）
| 指標 | 結果 | 合格ライン |
|---|---|---|
| 誤答（引用元にない内容） | **5件**（A015・A020・A040・A129・A148） | 0件 |
| 正答率 | **90.5%** | 85%以上 |
| 正しく答えなかった率（FAQにない60＋意地悪40） | **99.0%** | 95%以上 |
| 上位5件ヒット率 | **96.5%** | 95%以上 |
| 1問の neurons | 14.6 | — |

- 採点：回答した198問を Claude Code の担当2本が主張単位で照合（`out/grades_gemma4_all.jsonl`）。不合格は全部、合格の1割は人が見る（まだ）
- 誤答5件の型：要約が原文の条件・例外（「〜を除く」「〜に限る」）を落として対象を広げた4件、FAQ と向きが逆の手続きに当てはめた1件
- 直し（同日）：生成の指示に「条件・例外を省かない・『など』で広げない」、検証に質問と FAQ 全文を渡し「条件の落とし・状況の食い違い」を不合格にする → 誤答5件のうち4件が直った（A015 は「マイナ免許証のみ保有者が対象」をまだ落とす）。正しい10問のうち2問が原文表示に落ちた（安全側）。1問 約25 neurons に上がった（1日 約400問）

## Workers Paid（2026-11-26〜）
- 月5ドル。Workers AI は1日10,000 neurons まで無料、超えた分は $0.011／1,000 neurons（1問 約25 neurons＝約0.04円）
- Workers AI には支払いの上限を決める設定が無いので、`wrangler.jsonc` の vars で守る：DAILY_NEURONS 60,000（約2,400問・使い切って1日 約80円）、DAILY_ASKS 3,000
- 8割と10割で LINE に通知（`worker/src/notify.ts`）。上げ下げは vars を変えて `npm run deploy`

## 無料枠を超えたら（お金を払わずに止まらない）
1. その日の neurons の残りを D1 で数え、生成の分が尽きたら**検索だけの表示**に切り替える：上位3件の FAQ 原文と出典リンクを出す（生成なし＝誤答なし）
2. Vectorize の月の枠が尽きたら、キーワード検索だけに落とす
3. 「超えたら止まるだけで請求は来ない」は **Workers Free のアカウントのときだけ**。Workers Paid のアカウントだと、超えた分は請求される。このサービスは 2026-11-26 に Workers Paid に移した（上の節）ので、上限は vars（60,000 neurons・3,000問）で守る。1の切り替えはコードに入っている。2はまだ

## 荒らし・使いすぎへの守り（`worker/src/limits.ts`・`worker/src/index.ts`）
- 質問は、答えを作る前に `ask_log` に1行書いてから数える（D1 のまとめ実行＝1トランザクション）。答えが出てから書くと、同時に来た質問が互いを数えられず、上限を越える
- 1 IP（IPv6 は /64）20問／時、1日 3,000問、1日 60,000 neurons（vars。無いときは 700問・8,500 neurons。1問 25 neurons を先に見込む）。超えたら順に 429・`unavailable`・`search_only`
- `/api/ask` は JSON だけ・本文 4KB まで・別サイトのページからの送信は断る。応答は画面が使う項目だけ（内部の理由・類似度・neurons・検証に落ちた要約は `ask_log` にだけ残す）
- 手元の計測用（`/embed`・モデルの差し替え・計測用の項目）は、localhost かつ `LOCAL_EVAL=1` のときだけ
- 画面は CSP でインラインの script・style を禁止（`worker/public/_headers`）。API の値は `esc()` を通し、リンクは `http(s)://` だけ

## 評価の回し方
- 300問の計測は約4,200 neurons で1日の無料枠に収まる
- 採点（主張単位の照合）は Claude Code の中で行い、API の費用をかけない
- 1問あたりの費用は、0円の日でも「使った neurons」と円に換算した値を記録する（公式の1問約2,000〜4,000円との比較に使う）
