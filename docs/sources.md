# 追加できるFAQ出典の調査（issue #1）

調べた日：2026-11-26。総務省「Govbot FAQ データ」に無い質問を、ほかの公的なFAQで答えられるようにするための下調べ。

## 目的と判断の基準
- 今の出典は総務省のデータだけ。答えられない60問（`out/testset_unanswerable.jsonl`）のうち約20問は国の制度で、ほかの府省・機関がFAQを出している
- 各サイトの利用規約と見本のFAQページを実際に読んで判断した。読めなかったものは [要確認] と書いた
- 基準は次の4つ
  1. 利用条件：公共データ利用規約（第1.0版、以下 PDL1.0）か、それと同じ条件か。今と同じく「出典を書く・加工したと書く・国が作ったように見せない」で使えるか。転載・加工の禁止や除外がないか
  2. テストの60問のうち、いくつに答えられそうか
  3. 形：一覧ページ、1問1ページか、更新日、HTMLの取りやすさ、データ配布の有無
  4. 取り込みの手間（小・中・大）
- robots.txt は各サイトで確認した。FAQの場所を止めているサイトは無かった（外務省は robots.txt 自体が 403 で読めない）
- 問いの番号は `qid`（U001〜U060）

## おすすめの取り込み順
1. **国税庁 タックスアンサー**（最優先）：PDL1.0 で除外なし。約750件が1問1ページで見出しもそろい、基準日つき。U001・U042 に効く。税の質問は多いので60問以外にも効く
2. **厚生労働省（雇用保険Q&A＋労働基準FAQ＋生活保護ページ）**（2番目）：PDL1.0。小さなページ数で U035・U059・U036 に効き、U055 も一部効く
3. 文部科学省 就学支援金Q&A（U060）と大学入試センター（U045）：どちらも1ページで手間が小さい。センターは毎年取り直す
4. 法務省（U038・U044）：規約は問題ないが、ページの形がばらばらで手間が中
5. 日本年金機構・協会けんぽ：入れるなら引用だけで答える形にするか、相手に確認してから
6. 保留：外務省（読めない）、人事院、運輸局、確かめよう労働条件、政府広報オンライン
